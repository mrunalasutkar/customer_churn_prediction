Overview:-
This project focuses on predicting customer churn for a telecom company using machine learning. Customer churn refers to customers who stop using a service. Accurately identifying high-risk customers enables businesses to take proactive retention actions, reducing revenue loss.
This is an end-to-end ML project, covering data preprocessing, exploratory data analysis (EDA), model training, evaluation, explainability, and deployment using Streamlit.

Download Dataset:-
https://www.kaggle.com/datasets/blastchar/telco-customer-churn

Key Features:-
Customer demographics (gender, senior citizen)
Account information (tenure, contract type, payment method)
Service usage (internet service, streaming, tech support)
Billing information (monthly charges, total charges)
